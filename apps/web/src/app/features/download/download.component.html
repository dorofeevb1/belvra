Установка на iPhone

Belvra работает как полноценное приложение через Safari

1

Откройте в Safari

Перейдите на belvra.ru в браузере Safari на вашем iPhone. Другие браузеры не поддерживают установку.

2

Нажмите "Поделиться"

Нажмите на иконку ☩ (квадрат со стрелкой вверх) внизу экрана Safari.

3

На экран "Домой"

Прокрутите меню вниз и нажмите "На экран Домой".

4

Добавить

Нажмите "Добавить" в правом верхнем углу. Готово! Belvra появится на рабочем столе.

Приложение будет работать в полноэкранном режиме, без адресной строки, как нативное.

Установка на Android

Скачайте APK и установите приложение

Скачать APK
1

Скачайте файл

Нажмите кнопку выше. Файл belvra.apk загрузится на ваш телефон.

2

Разрешите установку

Если появится предупреждение, перейдите в Настройки → Безопасность и разрешите установку из неизвестных источников.

3

Установите

Откройте скачанный файл и нажмите "Установить".

APK скачивается напрямую с нашего сервера. Файл безопасен.
